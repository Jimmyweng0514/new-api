? 三种模式的区别

Generate · 绘图
纯文本到图像。只用提示词从零生成画面，不需要上传任何参考图。适合从想象中"无中生有"的创作。

Edit · 垫图
提供 1–8 张参考图 + 提示词。模型在保留参考图主体/风格的基础上重绘，可选搭配 Mask 蒙版做局部修改、或用 Outpaint 扩展画布。适合换风格、合成、修改细节。

Variations · 变体
提供 1 张原图，不需要提示词。模型在同主题/同构图下产生差异化的多个版本，适合做素材增殖。
